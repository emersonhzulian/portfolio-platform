A small platform, run like a real one.

This is a Kubernetes platform running in my homelab, reachable from the internet with zero open ports. Everything here is live, deployed by GitOps and observable - and there's a small shop running on it, so you can use it, not just look at it.

Follow your own purchase

  1. Open the shop and sign up (a username and a password, no e-mail) - or use the demo account shown on the login page.
  2. Buy something. Payment is simulated (Pix, no money moves) and confirmed by a webhook a few seconds later; the order page shows each step as it happens.
  3. The "paid" event goes through Kafka; a worker writes your PDF receipt, which you download from your own folder.
  4. On the order page, open its trace in Grafana: one trace, four services - the web request, the payment, its webhook, the Kafka event, the receipt and back.
  5. See the event itself in the Kafka UI, and the deployment it ran on in Argo CD.

How a request gets here

You→Cloudflare→Cloudflare Tunnel→ Envoy Gateway (TLS)→App→OpenTelemetry→ Prometheus · Loki · Tempo→Grafana

The gateway has no external IP. The tunnel is the only way in. cert-manager issues the TLS certificate and external-dns writes the DNS record for each route.

Under the hood

Two-layer GitOps

Flux bootstraps the platform (CNI, operators, Argo CD itself). Argo CD runs this product from its own folder. AppProjects cap what a commit here can create. Renovate opens the update PRs.

Secrets

OpenBao runs outside the cluster. External Secrets syncs credentials in, so Git only ever holds references.

Data & storage

PostgreSQL via CloudNativePG. Volumes come from TrueNAS over iSCSI and NFS, provisioned by democratic-csi.

Edge

Cloudflare + Cloudflare Tunnel → Envoy Gateway (Gateway API). Real client IP from CF-Connecting-IP and rate limits per visitor. cert-manager and ExternalDNS automate TLS and DNS.

Network

Cilium replaces kube-proxy, announces load balancers over L2 and gives visibility with Hubble. This namespace is default-deny in and out with plain Kubernetes NetworkPolicy. Cilium policies cover only what the native API can't express, such as outbound calls pinned to hostnames. Spegel shares container images between nodes.

Observability

OpenTelemetry Operator auto-instrumentation sends traces and logs to Tempo and Loki. Span metrics go to Prometheus. This stack is separate from the rest of the homelab's.

Identity

authentik: sign-up behind Cloudflare Turnstile, a read-only demo account, OIDC for the shop and - through the gateway itself - for FileBrowser. Flows and clients are blueprints in Git.

Messaging

Kafka via Strimzi (KRaft). A transactional outbox publishes the shop's events; the trace context travels in the message headers. The public UI's user is read-only at the broker (ACLs).

Policy

Kyverno, in CEL: pods are pinned to a dedicated node pool, mutable image tags are refused, and workload rules are audited on their way to being enforced.

Nodes

Talos Linux: immutable, API-driven and with no SSH. This namespace runs on its own pool of two nodes, one replica of each service per node.
